# Security policy

## Reporting a vulnerability

Please report security vulnerabilities privately to support@codecartpro.com. Include the affected release, reproducible steps and the potential impact. Do not publish credentials, private customer data or working exploits in public GitHub issues.

A report does not guarantee a specific response timeline. Maintainers will review it and coordinate any security fixes and disclosure.

## Support boundaries

The CodeCart core, optional modules, themes, payment gateways and hosting environment may have different supported PHP versions. Review the exact release documentation and test each integration on staging.

## Safe installation

Back up the website and database before installing or upgrading. Never upload production credentials or runtime storage to a public repository. Remove the web installer after successful setup.
