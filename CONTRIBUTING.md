# Contributing to CodeCart

Thank you for your interest in improving CodeCart.

1. Search existing issues before opening a new issue or proposing a change.
2. Describe the affected CodeCart build, PHP and database versions, active theme, and steps to reproduce.
3. Keep changes focused. Preserve the OpenCart/ocStore license and attribution notices in inherited code.
4. Do not add secrets, customer data, runtime logs or generated cache to commits.
5. Include an explanation and, when possible, a regression test for bug fixes.
6. Use a pull request for proposed code changes, and do not assume changes are accepted until reviewed.

Refer to `documentation/INSTALL.md` and `documentation/UPGRADE.md` for installation and migration precautions.

Contribution licensing terms must be confirmed by the maintainers before external contributions are merged; the source distribution contains upstream GPL-licensed components and a pending top-level license review.
